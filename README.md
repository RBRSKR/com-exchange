# COM EXCHANGE

디스코드 서버의 가상화폐 COM으로 즐기는 **가상 증권거래소** 시세 사이트입니다.

**사이트: https://rbrskr.github.io/com-exchange/**

- 상장 종목: 크리티컬 컴퓨터 Inc.(CCI) · 무당 세계관 그룹(MUG) · 사되 AI(SAI) · 다크 에너지 원자로(DER) · 리버수 얼음 광산(RIM)
- 가격은 매일 **08:00 · 17:00 · 22:00 (한국 시간)** 에 바뀌고, 하루에 ±15%까지만 움직입니다.
- 가끔 나오는 **시장 뉴스**에 따라 주가가 크게 오르거나 떨어질 수 있습니다.
- 사고팔기와 COM 지급은 디스코드에서 **사되**가 직접 처리합니다. 사이트에서 거래 신청 문구를 복사해 디스코드에 붙여넣으세요.

모든 회사는 실제 기업이 아닌 가상의 회사이며, 실제 돈이나 투자 상품과는 관계가 없습니다.
